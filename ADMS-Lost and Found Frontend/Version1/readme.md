Advanced Database-Driven Lost and Found Object Management System (ADMS) Frontend Version 1

Description
This project is a "Lost and Found Object Management System" where users can submit lost and found objects, and these objects are stored in a database. The frontend allows users to enter details such as object name, description, location, and date. It also displays the submitted objects in a table.

Tech Stack
- **HTML** for structure
- **CSS (Bootstrap)** for styling
- **JavaScript** for interactivity and API communication

Installation/Usage
1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/ADMS-Frontend-V1.git
    ```
2. Navigate to the project directory:
    ```bash
    cd ADMS-Frontend-V1
    ```
3. Open the `index.html` file in your browser.
